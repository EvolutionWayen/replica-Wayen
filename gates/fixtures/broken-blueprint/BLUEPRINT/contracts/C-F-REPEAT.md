# C-F-REPEAT · 设置与清除重复规则

## 1 目标与入口

用户意图：设置与清除重复规则（工作日 / 每周 / 自定义），改完立即在其他屏看到结果，不刷新页面。
- 主入口：重复 › 每周工作日（命令 `Cmd.SetRepeatWeeklyWorkdays`）
- 替代入口：行右键菜单、快捷键 `⌘D`、拖拽到日历某天
- 前置上下文：必须已有 1 条选中任务且在可写库中；无选中时入口整条禁用并提示「先选择任务」

## 2 界面与层级

控件顺序：标题输入框 → 日期行 → 重复行 → 提醒行 → 备注。
- 日期行点击后弹出浮层（320×380，贴住触发元素右下角，空间不足时翻转向上）
- 浮层内可滚动区为规则列表；底部固定「清除」与「确定」两个按钮
- 尺寸策略：浮层最小宽度 280，最大高度不超过窗口高度减 48

## 3 每个菜单选项

逐叶列全（对应 menus.csv 的 M-DATE 整棵子树）：
| 路径 | 类型 | 默认/当前项 | 打开关闭行为 |
|---|---|---|---|
| 重复 › 每周工作日 | 子菜单 | 无默认项 | 悬停 120ms 展开，点击保持打开 |
| 重复 › 每周工作日 › 今天 | 动作 | 无选中态 | 点击后收起并把日期置为今天 |
| 重复 › 每周工作日 › 明天 | 动作 | 无选中态 | 点击后收起并把日期置为次日 |
| 重复 › 每周工作日 › 自定义… | 动作 | 无选中态 | 打开日期浮层，浮层关闭后以提交值为准 |
- 鼠标跨层：移出子菜单 400ms 后收起，斜向移动穿透一层
- 键盘：↑↓ 移动、→ 展开子菜单、← 收起、Enter 执行、Esc 关闭并还原草稿

## 4 显示条件

出现条件：详情面板可见 且 当前任务在可写库中。
- 只读分享视图下整段隐藏，隐藏后菜单高度自动减少一行，不留空位
- 隐藏时焦点交给标题输入框，关闭浮层后焦点回到触发元素

## 5 可用与选择条件

可用 ≠ 已选中，两者分开实现：
- 可用条件：library.writable == true 且 flush.state != busy
- 禁用解释：不可用时整段灰化并在 tooltip 显示「正在保存，稍后可用」
- 互斥与组合：单选规则（今天/明天/自定义）互斥；周维度可多选 byday
- 最大选择数：byday 最多 7 个；取消选择即退出该规则
- 选中态来源：菜单勾选由数据库持久值决定；浮层内由草稿值决定，提交后才写库

## 6 筛选条件

无 AND/OR 嵌套；筛选只影响主列表可见行，不影响统计口径。
- 空值：dueDate 为空的任务不进入「今天/明天」筛选结果
- 边界日期：跨月、闰日、时区变更按设备本地时区归一后比较
- 排序：先按 dueDate 升序，同日期按创建时间降序
- 角标统计口径：未完成且 dueDate <= 今天 24:00 的任务数

## 7 业务实现逻辑

规则求值顺序：校验 → 归一化日期 → 计算重复实例 → 写库 → 广播事件 → 刷新受影响面。
- 默认规则：未指定时间时取 09:00 本地时间
- 参数：{taskId, dueDate|'YYYY-MM-DD', allDay:boolean, revision}
- 校验：revision 必须等于当前库中 revision，否则拒绝并提示冲突
- 算法边界：不调用外部服务；重复实例只在可见窗口内展开

## 8 具体效果

可复算的效果描述：
- 选中 dueDate=2026-10-24 的任务点「明天」→ 主列表该行徽标从「今天」变「明天」
- 详情面板日期字段立即显示 2026-10-24，聚焦状态与光标位置不变
- 日历视图该任务从 10-23 格移到 10-24 格，格内计数 +1/-1
- 提示条「已改为明天」显示 2.5 秒后淡出，不抢焦点

## 9 状态变化

原状态 → 事件 → 条件 → 目标状态 → 副作用：
- idle → SUBMITTING（提交）→ 成功 → idle，副作用：广播 TaskDateChanged
- SUBMITTING → 失败 → error（保留草稿），副作用：显示重试按钮
- SUBMITTING → 冲突 → conflict（不覆盖），副作用：提示「已在别处修改」
- 失败与冲突都不清空草稿；重试成功后回到 idle

## 10 数据读取

实体与字段：E01.repeat / E01.byday（见 data-dictionary.md E01）。
- 查询条件：按 taskId 主键读取，附 revision
- 派生值：相对文案（今天/明天/逾期 N 天）由 dueDate 与设备当前日期算出
- 数据新鲜度：读取走同一连接，写入后立即可见（WAL 模式下同连接一致性）
- 空库行为：空库时主列表显示空态而不是错误；异常库时给出可操作的提示

## 11 数据写入

命令与参数：`Cmd.SetRepeatWeeklyWorkdays{taskId, patch, revision}`。
- 精确字段：只写 E01.repeat / E01.byday、updatedAt、revision 三个字段，其余字段必须保持不变
- 事务范围：单行更新在单个事务内完成；事务提交成功后才广播事件
- 完成信号：返回 FlushResult{ok|unknown|error}，调用方 await 它
- 失败保留：写失败不丢草稿，草稿留在内存并由重试按钮重新提交

## 13 并发与生命周期

快速连点：同一 revision 的重复提交按幂等处理，第二次直接返回已成功的 FlushResult。
- A→B 切换：命令携带入队时捕获的 entityId，绝不读「当前选中」
- 迟到结果：读路径带 generation，过期结果直接丢弃
- 防抖：仅对输入框做 300ms 防抖，写命令不防抖
- 关窗/退出：先冲刷写队列，FlushResult 为 error 时阻止关窗并提示
- 重启/睡眠唤醒：启动时按 revision 校验，冲突行标注并在 UI 上提示

## 15 体验标准

输入法：中文组合输入期间不触发表单提交，Esc 先退出候选再关浮层。
- 焦点返回：执行后焦点回到触发元素，键盘可完成整条流程
- Esc/Enter：Esc 关闭并还原草稿，Enter 提交当前浮层值
- 可访问性：所有菜单项有可读标签，焦点环 2px 且对比度达 AA
- 布局稳定：浮层出现不引起主列表跳动（预留占位）
- 性能口径：点击到主列表可见更新的 p50 ≤ 80ms、p95 ≤ 200ms（本机 macOS，库 1 万行）

## 16 测试与证据

用例与断言（正常 / 负向 / 边缘 / 跨页面 / 立即退出重启）：
- T-102、T-103：正常路径，断言落库值等于预期具体值
- 同一用例覆盖跨页面：主列表徽标、日历格计数、角标数值三处都要断言
- 负向：只读库写入 → 返回 FlushResult.error 且草稿仍在
- 边缘：跨月、闰日、时区切换各一条
- 截图不能代替落库证明：必须查询数据库断言具体值
