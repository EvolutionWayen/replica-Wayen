# S5 · 设计系统

> 上游：冻结蓝图 + 原版截图 + S4 架构 · 下游：S6 逐屏重建 · 门禁：G5

## 一句话

把原版截图量成**数字**（色值、间距、字号、圆角、阴影、动效时长），写成一份机器可校验的令牌文件，再给每个组件定死六个状态；从这一刻起「好看」不再是形容词，而是 `tokens.json` 里的一个值。

## 输入

| 从哪来 | 文件 | 缺了就不许开工 |
|---|---|---|
| 原版截图 | `screens/` 或 `evidence/shots/`（同缩放比、同窗口尺寸） | 截图尺寸/缩放不一致 → 量出来的数字互相矛盾，停 |
| 冻结蓝图 | `menus.csv` 三条件 + `contracts` §2/§15 | 缺 §2 界面层级 → 组件边界定不出来 |
| 架构 | `SPEC/ARCHITECTURE.md` 分层 | 缺 → 不知道组件该放在哪一层 |
| 交互规格 | `screens.csv` 的 `focus_restore` 列 | 缺 → 焦点行为无法写进组件规格 |
| 替换决策 | `DECISIONS.md` 中字体/图标授权相关行 | 缺 → 可能把原版专有资产画进产品 |

**开工前的硬要求**：所有参考截图先验格式与缩放比——`file screens/*.png`（扩展名必须与实际格式一致，曾出现 `.png` 实为 WebP）+ `sips -g pixelWidth -g pixelHeight screens/S-01-main.png`。

## 动作序列

### 1 · 量像素取数（90 分钟，不许靠肉眼）

对每张基准截图跑扫描，取边界与色值：

```python
# WCAG 对比度（量出来的每个值都写「采样坐标」，别人能复算）
def contrast(a, b):
    def L(c):
        f = lambda v: (v/255)/12.92 if v/255 <= 0.03928 else (((v/255)+0.055)/1.055)**2.4
        return 0.2126*f(c[0]) + 0.7152*f(c[1]) + 0.0722*f(c[2])
    return (max(L(a),L(b))+0.05)/(min(L(a),L(b))+0.05)
```

取数纪律四条：

| 纪律 | 具体要求 | 违反的后果 |
|---|---|---|
| 同缩放比 | retina 一律按 2x 取，除以 2 再写进令牌 | 尺寸全部翻倍 |
| 量像素不量感觉 | 每个数值附采样坐标（`x=322,y=900`） | 无法复算，等于猜 |
| 色值判定分两类 | 结构色 hex 必须相等；文字色允许 ΔRGB ≤3 | 把「近似」当「一致」 |
| 格式先验 | `file` 必须与扩展名一致；不一致先转码 | 读图失败或读错通道 |

### 2 · 定色板（45 分钟）

令牌里的颜色**只写角色名，不写用途**：

```json
{
  "color": {
    "bg": "#FFFFFF", "surface": "#F2F2F2", "border": "#E9E9E9",
    "text": "#1A1A1A", "text-muted": "#6E6E73",
    "accent": "#0071E3", "on-accent": "#FFFFFF",
    "danger": "#C0392B", "success": "#00C598", "warning": "#FF3B30"
  },
  "pairs": [
    {"fg": "text", "bg": "bg", "min": 4.5},
    {"fg": "on-accent", "bg": "accent", "min": 4.5},
    {"fg": "text-muted", "bg": "bg", "min": 4.5}
  ]
}
```

**复刻不等于复制缺陷**（这是 S5 最容易搞错的一条）：

| 属性类别 | 处理 | 例子 |
|---|---|---|
| 结构属性（必抄） | 栏宽、行高、分隔线位置、圆角档位、层与层的顺序 | 侧边栏 239px、分隔线 1px `#E9E9E9` |
| 可用性属性（按下限抬升） | 文字色对比度、选中态的线索、热区尺寸 | 原版 11px `#9B9B9B`=2.78:1 → 改成 `#6E6E73`=5.07:1 |
| 专有资产（必须替换） | 系统符号库、专有字体、原版图标 | SF Symbols → 自绘 Path |

抬升的每一条都要记 `DECISIONS.md` 为「有意差异」，并在 S9 打分时豁免。

### 3 · 定排版与间距（45 分钟）

| 项 | 规则 | 判定 |
|---|---|---|
| 间距栅格 | 基数 4px，焦点区允许 2px 微调 | 令牌里所有 `space` 值都是 4 的倍数（或 2） |
| 档位数量 | 字号 4 档、圆角 3 档 + 胶囊、组内间距 3 档 | 档位数超过即 FAIL（这是「看起来便宜」的头号原因） |
| 同屏内边距 | 最多 2 种 | 数一遍主区/详情/弹窗的内边距种类 |
| 阴影 | 全局唯一一档（同层浮层完全一致） | 两处浮层阴影参数不同即不合格 |
| 热点尺寸 | 窄屏指针 ≥28×28，高频 ≥40×40 | 每个可点元素都量 |

```json
{
  "font": {"title": {"size": 21, "weight": 600}, "h2": {"size": 13, "weight": 600},
           "body": {"size": 13, "weight": 400}, "caption": {"size": 11, "weight": 400}},
  "space": {"xs": 4, "sm": 8, "md": 12, "lg": 16, "xl": 24},
  "radius": {"ctl": 6, "box": 8, "pop": 14, "pill": 999},
  "shadow": {"pop": "0 6 24 0 #22000000"},
  "motion": {"state": "120ms ease-out", "pop-in": "180ms cubic-bezier(0,0,0.2,1)", "pop-out": "120ms ease-in"}
}
```

### 4 · 写 components.md（90 分钟，每组件六状态）

**每组件必须列全六态**：`default` / `hover` / `focus` / `disabled` / `loading` / `error`。少一个状态 = G5 FAIL。另外补 `selected`（有选中语义的组件）。

每组件一段，固定结构：

```markdown
### Button · 主按钮
| 状态 | 背景 | 文字 | 边框 | 其他 |
|---|---|---|---|---|
| default | accent | on-accent | 无 | 圆角 ctl, 内边距 8/16 |
| hover | accent（不透明度 0.92） | on-accent | 无 | 120ms ease-out |
| focus | accent | on-accent | 2px #0071E3 外环 | 焦点环与背景对比 ≥3:1 |
| disabled | border | text-muted | 无 | 不响应点击，有 ToolTip 解释原因 |
| loading | accent | on-accent | 无 | 文字替换为 16px 转圈，宽度不变（防跳变） |
| error | danger | on-accent | 无 | 可重试；文案说人话 |
行为：Enter/Space 触发；Esc 不触发；键盘焦点可见（R11 可验收）
```

**判据不是「写了六行」，而是「六个状态能各自实现出来且互相不混淆」**。判定问句：「hover 和 focus 同时成立时显示什么？」——答不出来说明没定完。

### 5 · 建替换表（30 分钟，防专有资产进产品）

| 原版资产 | 类型 | 替换方案 | 验证 |
|---|---|---|---|
| 系统符号库图标 | 专有 | 自绘矢量 Path，描边 1.4px 圆头，4 档尺寸 12/15/16/17 | 同尺寸描边粗细差 ≤0.2px、端点圆角一致 |
| 专有字体 | 授权 | 开源等效（写明字体名 + 许可证 + 下载来源） | 字号档位与行高不破版 |
| 原版图标形状 | 版权 | 重画（只保留功能语义，不描摹轮廓） | 与原图并排看，不构成实质相似 |
| 原版文案 | 版权 | 全部重写（功能名可同，句式必须不同） | `sweep.py` 0 命中 |

替换表的每一行都必须有「替换方案」与「验证方法」。**空着就是没决定。**

### 6 · 跑对比度门（20 分钟）

```bash
python3 replica-skill/replica-design/contrast.py SPEC/DESIGN/tokens.json
```

要求：**0 失败**。失败项不许手改数字凑过，必须改色值并重新量。WCAG 阈值：正文 4.5:1，大字（≥18.66px bold 或 ≥24px）3:1，非文本元素 3:1。

### 7 · 写 tokens.css（20 分钟）

`tokens.json` 与 `tokens.css` 必须一一对应（同一份值两种格式，供不同技术栈消费）：

```css
:root {
  --bg:#FFFFFF; --surface:#F2F2F2; --border:#E9E9E9; --text:#1A1A1A; --text-muted:#6E6E73;
  --accent:#0071E3; --on-accent:#FFFFFF; --danger:#C0392B; --success:#00C598; --warning:#FF3B30;
  --r-ctl:6px; --r-box:8px; --r-pop:14px; --r-pill:999px;
  --font-title:21px; --font-body:13px; --font-caption:11px; --motion-state:120ms ease-out;
}
```

判据：`grep -o '\-\-[a-z-]*' tokens.css | sort -u` 的键集合，与 `tokens.json` 的键路径能对上（脚本可核）。

### 8 · 跑 G5（10 分钟）

`python3 gates/run.py --stage G5 --project .`，退出码 0 才结束。

## 细节级产出

| 文件 | 最小内容 | 判定它「够细」的标准 |
|---|---|---|
| `SPEC/DESIGN/tokens.json` | `color`（角色名全 10 个）/`font`/`space`/`radius`/`shadow`/`motion`/`pairs` | `contrast.py` 0 失败；`space` 全是 4 的倍数；字号 4 档、圆角 3 档+胶囊、无多余档位；每个色值都能指到一张截图的采样坐标 |
| `SPEC/DESIGN/tokens.css` | 与 json 一一对应 | 键集合比对通过；无硬编码色值散落在组件里（后期脚本可查） |
| `SPEC/DESIGN/components.md` | 每组件六态 + 行为段 | 每组件六态无空行；「hover 与 focus 同时成立显示什么」有答案；`disabled` 有解释文案 |
| 替换表 | 原版资产 → 替换方案 → 验证方法 | 无空行；每行有验证方法；专有资产 0 残留（S11 的 `sweep.py` 兜底） |
| `DECISIONS.md` 追加 | 所有「刻意不同」的条目（对比度抬升、字体替换、动效降级） | 每条都有理由与影响范围；S9 打分时能据此豁免 |

## 门禁 G5

### 机器判定（`gates/rules/g5.py`）

| # | 检查项 | 期望 | 不通过怎么修 |
|---|---|---|---|
| 1 | `tokens.json` 结构完整 | 七个键都在，`color` 含 10 个角色名，`pairs` 非空 | 按模板补齐；角色名不许改名 |
| 2 | 对比度 0 失败 | `contrast.py` 退出码 0 | 改色值重测，不许改阈值 |
| 3 | 每组件状态齐 | `components.md` 里每个组件都有六态行且非空 | 补状态；确实不适用写理由 |
| 4 | 档位数量合规 | 字号 ≤4 档、圆角 ≤3 档+胶囊、`space` 值全为 4 倍数 | 合并档位 |
| 5 | 替换表无空项 | 每行有「替换方案」与「验证方法」 | 决定方案并写出来 |
| 6 | `tokens.css` 与 json 对应 | 键集合能对上 | 重新生成 css |
| 7 | 无原版素材残留 | `screens/` 之外无原版图标/字体文件被复制进 `src/` 或 `SPEC/` | 删掉，改用替换方案 |

### 人工判定（产品官，Agent 不得自批）

| # | 判什么 | 判定问句 |
|---|---|---|
| 1 | 视觉气质是否对 | 「把你做的和原版截图并排放，第一眼像不像？」（先不看细节） |
| 2 | 刻意差异是否接受 | 「文字色我抬亮了因为原版对比度不达标，你接受这个不同吗？」 |
| 3 | 档位是否收敛 | 「这一屏你用了几个圆角、几种内边距？」——超 3 档要解释 |
| 4 | 焦点与悬停是否可感知 | 「用键盘 Tab 过去，你看得出现在在哪个控件上吗？」 |

## 常见翻车点

| # | 症状 | 真因 | 对策 |
|---|---|---|---|
| 1 | 界面像了但用起来别扭（失效模式 19） | 只对视觉，没对操作步数与焦点行为 | `components.md` 必须有 `focus` 态；`screens.csv` 的 `focus_restore` 进组件规格 |
| 2 | 原版的可访问性缺陷被一起复刻 | 把「1:1 复刻」误解为「色值也必须一致」 | 区分结构属性（必抄）与可用性属性（按下限抬升）；抬升项记 `D-` 并在 S9 豁免 |
| 3 | 把专有资产画进产品 | 用了系统符号库或原版图标 | 替换表强制每行有验证方法；S11 `sweep.py` 兜底 |
| 4 | 每屏都好看，放一起不像一个产品 | 没有令牌，逐屏手调 | 令牌是唯一来源；组件样式只能引用令牌，不许硬编码色值 |
| 5 | 对比度检查过不了，改阈值凑过 | 把门禁当障碍而不是护栏 | 阈值不可改（R20 的变体）；改色值 |
| 6 | 状态只写了 default/hover，disabled 与 loading 全空 | 六态被当成「有争议时才写」 | G5 机器判定 3 强制六态；空行即 FAIL |
| 7 | 动效写了「流畅的动画」 | 违反 R11（不可验收） | 动效必须写成「时长 + 曲线 + 位移量」，如 `180ms cubic-bezier(0,0,0.2,1)` + 位移 ≤4px |

## 示例

### 示例 1 · 四栏尺寸实测（结构性 token 的取数方式）

| 元素 | 原版实测（2x 截图换算后） | 令牌 | 判定 |
|---|---|---|---|
| 图标栏 | 61px | `--w-iconbar: 61px` | 误差 ≤2px |
| 侧边栏 | 239px | `--w-sidebar: 240px` | 误差 1px，接受 |
| 主区 | 498px | 弹性 | — |
| 详情 | 298.5px | `--w-detail: 299px` | 误差 0.5px |
| 竖直分隔线 | 3 条：x=322 `#E9E9E9`、x=802 `#F4F4F4`、x=1800 `#F4F4F4` | `--border: #E9E9E9` | 结构色必须相等 |

这张表的价值在于：**「分隔线 3 条」是一个可以判 FALSE 的事实**，而「分隔线看着挺清楚」不是。

### 示例 2 · 对比度抬升（复刻不复制缺陷）

| 用途 | 原版 | 对比度 | 本版 | 对比度 | 处置 |
|---|---|---|---|---|---|
| 正文次要文字 11px | `#9B9B9B` on `#FFFFFF` | 2.78:1 不通过 | `#6E6E73` | 5.07:1 通过 | 抬升，记 `D-` |
| 说明框 10px on 灰底 | `#9B9B9B` on `#F2F2F2` | 2.48:1 不通过 | `#6E6E73` | 4.53:1 通过 | 抬升，记 `D-` |
| 主按钮白字 on 品牌蓝 | `#FFFFFF` on `#0093FD` | 3.19:1 不通过 | `#FFFFFF` on `#0071E3` | 4.70:1 通过 | 换蓝，记 `D-` |
| 危险色 | `#C0392B` on 白 | 5.44:1 通过 | 同原版 | 5.44:1 通过 | 照抄 |

### 示例 3 · 组件六态的一段（Button）

```markdown
### Button · 主按钮
| 状态 | 背景 | 文字 | 边框 | 其他 |
|---|---|---|---|---|
| default | `--accent` | `--on-accent` | 无 | 圆角 `--r-ctl`，内边距 8/16 |
| hover | `--accent` @ 0.92 不透明 | `--on-accent` | 无 | `120ms ease-out` |
| focus | `--accent` | `--on-accent` | 2px `#0071E3` 外环 | 外环与背景 ≥3:1 |
| disabled | `--border` | `--text-muted` | 无 | 不响应点击，ToolTip 说明原因 |
| loading | `--accent` | `--on-accent` | 无 | 转圈替换文字但**宽度不变**（防跳变） |
| error | `--danger` | `--on-accent` | 无 | 可重试，文案说人话 |
```

「loading 时宽度不变」这一句就是一条可验收的断言——它防的是「按钮转圈时整行布局跳一下」。

## 退出与交接

| 交接物 | 门槛 | S6 怎么用 |
|---|---|---|
| `tokens.json` / `tokens.css` | `contrast.py` 0 失败、档位合规 | 逐屏重建时**只许引用令牌**，不许硬编码色值 |
| `components.md` | 每组件六态 + 行为段 | 每屏的控件都要能对到某个组件规格；对不到的说明组件库缺一个 |
| 替换表 | 无空项 | 建界面时按表取替换资产，不许临时找 |
| `DECISIONS.md` 差异条目 | 每条有理由 | S9 打分时据此豁免，不参与扣分 |

**交接状态要求**：G5 退出码 `0`；对比度 0 失败；无原版素材进入产品目录。

**下一个接手的人需要知道的唯一一句话**：所有视觉决定都已经是数字，写界面时不许新造色值、新造圆角、新造间距——缺了就去加令牌，加令牌要跑对比度门。
