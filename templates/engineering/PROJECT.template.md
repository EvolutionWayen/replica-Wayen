## 一句话定位

为 ______，解决 ______（什么场景下的什么问题，带频次），方式是 ______（平台与交付形态）。

> 三条自检：① 主语是**人**不是「用户」；② 问题带场景与频次；③ 形态说清平台与交付方式。

## 目标制品

| 项 | 值 |
|---|---|
| 名称与版本 | （如 `目标应用 8.x`；版本从 `Info.plist` / 文件名读，不写「最新版」） |
| 安装包 SHA-256 | （64 位十六进制；Web 目标写「取证方式：URL + 采集时间 + 页面快照 SHA-256」） |
| 平台与形态 | 原生 Mach-O / .NET 托管 / Electron-Web |
| 架构 | （如 `x86_64 arm64`） |
| 签名状态 | （如 `Developer ID`、`ad-hoc`、`未签名`） |
