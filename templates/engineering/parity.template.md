> 复制为 `REPORT/parity.md`。
> **G9 判定三条**：① 文件里的「功能分」数字必须与 `features.csv` 实算一致（误差 ≤1，不许手填）；② 「界面分」必须单独出现在文里（不参与抵消功能分）；③ 必须有能反驳的缺失清单。
> 计价规则（脚本算，不许手算后填）：weight must 3 / should 2 / could 1；progress yes 1 / partial 0.5 / no 0；`scope=out` 与 `original=no` 剔除不计。

## 界面分

四项判据，**同时成立才给 90 分**：

| 判据 | 机器可判 | 阈值 | 本次结果 | 证据 |
|---|---|---|---|---|
| ① 逐项打勾表通过率 | 是 | ≥90% 且缺失项 = 0 | | `diffs/<S-id>.md` |
| ② 关键尺寸误差 | 是 | 栏宽/行高/热区/按钮 ≤2px；弹窗 ≤4px | | 像素扫描记录 |
| ③ 关键色值 | 是 | 结构色 hex 相等；文字色 ΔRGB ≤3 | | 采样坐标 + 色值 |
| ④ 盲测 | 否（人） | 3 个独立评审指出差异 ≤2 条且无结构性差异 | | `REPORT/blind-test.md` |

档位对照：90–100 看不出差别（可交付）／75–89 像但能指出细节／60–74 明显便宜（不得交付）／<60 重做。
