# DECISIONS —— 决策台账

> 复制为 项目根 `DECISIONS.md`。**当天记录，当天落库。**
> 作用：后续所有分歧用这份记录裁决；也是 G0（≥3 条）与 G3（确认记录）的判定对象。

## 用法

- 每条一行，**带日期、理由、影响范围**（影响范围必须是具体 ID，不许写「相关模块」）。
- **只追加，不改行**。决策被推翻时新增一行写「推翻 D-00x，原因」，旧行保留。
- 冻结项（不再讨论）标「已定」。
- 日期用 ISO 8601 带时区：`2026-10-23T14:12+08:00`。

## 各阶段典型要记什么

| 阶段 | 典型决策 | 影响范围怎么写 |
|---|---|---|
| S0 | 档位、制品选择、数据所有权 | `PROJECT.md`、`.replica/gate.manifest.yml` |
| S3 | 每个「改」与「不做」的判词 | `C-F-xxx` §编号、`U-xxx`、`F-xxx`、`LK-xxx` |
| S4 | 技术栈 + **落选方案淘汰理由** | `SPEC/ARCHITECTURE.md`、`SPEC/schema.sql` |
| S5 | 有意差异（对比度抬升、字体替换、动效降级） | `SPEC/DESIGN/tokens.json`、`components.md` |
| S9 | 豁免项（有意差异不参与扣分） | `REPORT/parity.md` |
| S10 | 改进项做/不做 | `features.csv` 行、`CHANGES/C-xxx.md` |
